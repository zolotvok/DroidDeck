# DroidDeck 0.4.0-mali.1 (unofficial Mali fork)

An unofficial build of [DroidDeck](https://github.com/Droid-Deck/DroidDeck) 0.4.0 with experimental Mali GPU support. It is not made or supported by the DroidDeck team: report problems in [this fork's issues](https://github.com/zolotvok/DroidDeck/issues).

**Tested on one phone only:** vivo X300 Pro (MediaTek Dimensity 9500, Mali-G1-Ultra MC12, Android 16).

### Mali system driver, built in

- The APK now **bundles [Blobferry](https://github.com/zolotvok/blobferry)**. Blobferry is the "Mali system driver (bridge)": games draw with the phone's own Mali Vulkan driver, while Steam, gamescope and the desktop stay on the open PanVK driver.
  - On a Mali phone the driver shows up on the **Runtime driver** page by itself. There is no zip to import and no adb step.
  - The app reinstalls the bridge files into the Linux runtime at every session start, so they stay in step with the APK.
- **Pick the driver per game.** Add `DROIDDECK_GAME_DRIVER` to a game's environment, or use the **Templates** button:
  - `bridge`: the phone's own Mali driver;
  - `session`: PanVK.

  This overrides the runtime driver choice for that game only.
- **New options in the game environment editor**, each with a description:
  - the Mali FPS log;
  - GPU timing;
  - render-target compression;
  - the FragDepth fix;
  - BC texture compression;
  - `VKD3D_DISABLE_EXTENSIONS`.
- **Templates:** save a game's environment entries under a name and add them to other games in one step, or copy them from another game. Three templates are built in:
  - Mali system driver;
  - Open driver (PanVK);
  - Measuring.
- **Performance › Mali system driver** has two new switches, **FPS log** and **GPU timing log**, and shows the bundled Blobferry version.
- The DX12-only **The Witcher 3** (current release) skips the REDprelauncher, which crashed under Proton. It starts from Steam and runs on the bridge, at about 19 FPS in the open world on the test phone.
- Hungarian translations for the Mali settings.

### Install

1. Install the APK. It updates a DroidDeck 0.4.0 build of this fork in place; your games and settings stay. An official DroidDeck build is signed with a different key and must be uninstalled first, which removes its data.
2. Turn off **Restrict child processes** in Developer options, as for DroidDeck.
3. Install the Linux runtime and import a PanVK-kbase (glibc) driver zip under **Runtime driver** (see the README's Mali section).
4. Choose **Mali system driver (bridge)** as the runtime driver, or pick it per game (see above). Start a session.

### Known limits

- DX12 games run without vkd3d-proton's descriptor buffers on the bridge: with them the picture is black. This is set by default (Performance › Mali system driver).
- Performance depends heavily on the phone's power state. At a low battery level the same scene ran about 30 % slower.
- No release APK with the store engines (GOG, Epic, Amazon) yet: this build is a debug build without them.
